# power_parts/ — statistical power modules

Submodules behind `power_analysis.py`/`power_study.py`: `analytic.py` (two-sample power, MDE), `permutation.py` (permutation test, no scipy), `effect_size.py`, `normal.py`, `diagnosis.py` (design diagnosis). Pure computation; I/O lives in `scripts/run_power_analysis.py`.
