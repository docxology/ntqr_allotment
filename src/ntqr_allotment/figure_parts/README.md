# figure_parts/ — figure modules

Per-figure builder modules consumed by `figures.py`, sharing a font/claim-title readability theme: `schematic.py`, `ranking.py`, `heatmaps.py`, `mechanism.py`, `phase.py`, `independence.py`, `empirical.py`, `fairness.py`, `power.py`, plus shared helpers in `_common.py`. Figures read regenerated `output/data/` artifacts only.
